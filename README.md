# The Nightman Cometh

A planned Python/pygame browser platformer based on Charlie's stage musical, with Philadelphia scenery, three acts, recognizable chiptune arrangements, and comic combat.

**Status: planning only. No playable game or approved soundtrack exists yet.** Repository creation was requested, but this matching public repository already existed; its history and visibility are preserved.
